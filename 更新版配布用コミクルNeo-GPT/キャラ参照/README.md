# キャラクター参照画像フォルダ

キャラクター設定は3つのモードから選べます。
フォルダを使わないモード1がデフォルトです。

---

## モード1: 全部お任せ（デフォルト）

**このフォルダに何も置かなくてOKです。**
主人公からサブキャラまで全員をAIが設計・生成し、外見の統一も自動で行います。

---

## モード2: 主人公だけ自分で用意

主人公の全身立ち絵をこのフォルダに置きます。サブキャラはAIが自動生成します。

```
キャラ参照/
  主人公名/
    主人公名.png            ← 全身立ち絵（必須）
    character_prompts.md   ← 外見・性格の定義（任意）
```

---

## モード3: 全キャラ自分で設定

主人公＋全サブキャラの画像と定義を置きます。

```
キャラ参照/
  主人公名/
    主人公名.png            ← 全身立ち絵（必須）
    character_prompts.md   ← 外見・性格の定義（任意）
  サブキャラ1名/
    サブキャラ1名.png
    character_prompts.md
  サブキャラ2名/
    サブキャラ2名.png
    character_prompts.md
  （登場人物の数だけ作成）
```

電子書籍生成時に「モード3で、キャラ参照/フォルダのキャラクターを使ってください」と
指示してください。
