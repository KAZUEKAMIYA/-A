コミクル Neo-GPT

電子書籍＋漫画 完全自動生成

テーマを入力するだけで、原稿・挿絵・漫画・Word ファイルを全自動で生成します

使う前に必ずご確認ください
⚠

OpenAI の組織認証（Verification）を先に完了してください

このシステムは画像生成に OpenAI の gpt-image-2 を使います。
このモデルは 組織認証（Organization Verification）を通過していないと利用できません。

認証の場所：OpenAI Platform にログイン → Settings → Organization → Verifications
認証が完了してから次の手順に進んでください。

📋

目次は自動生成されません。必要な場合は自分で作成してください

生成される final_book.docx には目次は含まれていません。
Kindle 出版などで目次が必要な場合は、Word の「参考資料」タブから手動で挿入してください。

📚

完成した Word ファイルは Kindle Previewer で最終確認してください

生成された final_book.docx を Word で開くと、漫画ページ前後に空白ページが表示されることがあります。
これはファイルの不具合ではありません。

Kindle Previewer アプリで開いて正常に表示されれば問題ありません。
Kindle Previewer は Amazon の公式サイトから無料でダウンロードできます（Windows・Mac 両対応）。

Claude デスクトップアプリ

Claude の公式デスクトップアプリを使う方

⚙

Claude Code（CLI）

ターミナルから Claude Code を使う方

💻  Claude デスクトップアプリを使う場合 必要なセットアップ：1ステップのみ
1

OpenAI の API キーを取得して .env ファイルに設定する

同梱の OpenAI_APIキー取得マニュアル を参照して API キーを取得し、
このフォルダにある .env ファイル を開いて以下のように記入し、上書き保存（Windows: Ctrl+S、Mac: Command+S） してください。

OPENAI_API_KEY=sk-...（取得したキー）

.env ファイルが見当たらない場合：Windows はフォルダオプション、Mac は Finder で Command+Shift+. を押して隠しファイルを表示してください。

⚙  Claude Code（CLI）を使う場合 初回のみ
1

OpenAI の API キーを取得して .env ファイルに設定する

同梱の OpenAI_APIキー取得マニュアル を参照して設定してください。

OPENAI_API_KEY=sk-...（取得したキー）
2

Node.js をインストールする

Node.js 公式サイトからバージョン 18 以上をインストールしてください。

3

Claude Code をインストールする

npm install -g @anthropic-ai/claude-code

Claude Pro プラン以上のご契約が必要です。

4

Python パッケージをインストールする

pip install python-docx Pillow openai python-dotenv
5

Pandoc をインストールする

Word ファイルの生成に使用します。

winget install pandoc

Mac の場合：brew install pandoc

6

Claude Code を起動する（毎回）

ターミナルでこのフォルダへ移動して起動してください。

cd "このフォルダのパス"
claude
使い方 ― Claude に聞かれること

起動後にテーマを伝えると、Claude から以下の項目がまとめて一度に聞かれます。
すべて答えると、あとは全自動で約 30〜60 分かけて生成が完了します。

💬 Claude からまとめて聞かれる内容（一度に全部来ます）
項目1
テーマ
作りたい電子書籍のテーマを入力してください。
例：「AIを使った副業の始め方」「40代からの資産運用」など
項目2
カラーモード
フルカラー（推奨）か 白黒 を選びます。
迷ったら「フルカラー」でOKです。
項目3
キャラクター設定
全部お任せ（推奨）：AIがキャラを自動設計します
主人公だけ自分で用意：「キャラ参照」フォルダに画像を置いておく
全員自分で用意：全キャラの画像を「キャラ参照」フォルダに置く
初めての方は「全部お任せ」がおすすめです。
項目4
1章あたりの漫画ページ数
章ごとの漫画ページ数を指定します。
デフォルト（推奨）は 3〜5 ページ。全5章なので最大 25 ページになります。
項目5
漫画の配置位置
章末（推奨）：各章の最後に漫画を配置
章頭：各章の最初に漫画を配置
迷ったら「章末」でOKです。
✓  ここまで答えたら、あとは全自動で完走します。途中で止まった場合は「続けて」と入力してください。
💡

これ以外にもカスタマイズできます。希望があれば伝えてみてください

項目として聞かれなくても、テーマと一緒に伝えるとその通りに作ってくれます。

例：章数を変えたい（「全7章で作って」）、文字数を変えたい（「1章あたり3,000字で」）、ターゲット読者を指定したい（「30代の会社員向けに」）、文体を指定したい（「親しみやすい口語体で」）など、
自由に希望を伝えてみてください。

よくある質問
「403 エラー」や「認証エラー」が出て画像が生成されない
OpenAI の組織認証が完了していない可能性があります。OpenAI Platform の Settings → Organization → Verifications で認証を完了してください。
Word ファイルに空白ページが表示される
Kindle Previewer アプリで開いて正常に表示されれば問題ありません。Word での表示上の現象です。
途中で処理が止まった
チャット欄に「続けて」と入力してください。API の制限の場合は 1〜2 分待ってから入力してください。
.env ファイルが見当たらない
隠しファイルの表示が必要です。Windows はフォルダオプション、Mac は Finder で Command+Shift+. を押してください。
