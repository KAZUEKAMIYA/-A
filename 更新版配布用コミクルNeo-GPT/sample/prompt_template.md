# 電子書籍+漫画 自動生成プロンプト（コピペ用テンプレート）

以下をClaude Codeにそのまま貼り付けて使ってください。
`{...}` の部分だけ自分の情報に書き換えてください。

> コマ割り・セリフ縦書き・読み順・画像サイズ・キャラシート先行生成・進行ルール等は
> CLAUDE.md に定義済みのため、プロンプトに書く必要はありません。

---

```
電子書籍と漫画を自動生成してください。

■ 参考資料
{テキストデータの入ったフォルダのパス}
※この中のデータを分析して、独立した書籍テーマ候補を5個以上提案してください。
※ユーザーが選んだテーマに絞って1冊を作成します。
※1つのフォルダから複数回に分けて別テーマの書籍を作成する想定です。

■ キャラ設定
・キャラ名: {キャラ名}
・外見定義: {キャラ参照フォルダ内のcharacter_prompts.mdのパス}
・参照画像: {キャラ参照フォルダのパス（例: キャラ参照/主人公名/）}
※主人公のみ指定。他キャラはテーマに合わせて自動生成してください。

■ 構成
・本文: はじめに + 全5章 + おわりに
・図解: 各章3枚（計15枚）
・漫画: プロローグ → 第1章〜第5章 → エピローグ（計100ページ）
・フルカラー
・章タイトル、サブキャラ、ストーリー展開等は参考資料から自動生成

■ DOCX配置ルール
・以下の順序で配置すること（章ごとに文章→漫画を交互に配置）:
  はじめに → プロローグ漫画 → 第1章（文章）→ 第1章漫画 → 第2章（文章）→ 第2章漫画 → 第3章（文章）→ 第3章漫画 → 第4章（文章）→ 第4章漫画 → 第5章（文章）→ 第5章漫画 → エピローグ漫画 → おわりに
・DOCXの章見出しは通常通り入れる
```

## CLAUDE.md が自動で処理してくれること（プロンプトに書かなくてOK）

| 項目 | CLAUDE.mdのルール |
|------|------------------|
| コマ割りテンプレート | コマ割りテンプレ (1024 x 1536 px)/ を自動参照 |
| コマの読み順 | 右→左、上→下（逆Z順）を全ページに自動適用 |
| セリフ縦書き | 吹き出し内テキストは全て縦書きで自動描画 |
| 章タイトル描画禁止 | 漫画画像内に章タイトルを描画しない |
| 英語プロンプト指示文 | Panel reading order... の指示を全ページに自動埋め込み |
| 画像サイズ | 漫画=1024x1536固定、挿絵=場面に応じて自動選択 |
| 画像生成API・認証 | scripts/openai_image_gen.py + .env を自動使用 |
| キャラシート先行生成 | サブキャラの全身立ち絵を漫画生成前に自動生成 |
| キャラ参照画像の使用 | 全キャラの参照画像を全ページでimages.edit()に自動適用 |
| 初回セットアップ案内 | .env確認・pip install案内を自動表示 |
| 進行ルール | セットアップ後は確認なしで全自動進行 |
