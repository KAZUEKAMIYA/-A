## 1. Claude使用料の設定（最初のお知らせ）

### 追加使用量の設定を確認しよう

| 設定項目 | 場所 | 推奨値 |
|----------|------|--------|
| 追加使用量 | Claude設定 → 使用料 | **オフ** or 上限$1〜$20 |
| 月額上限 | 同上 | 無制限は絶対NG |

**注意**: 追加使用量を「無制限」にすると請求が青天井になる可能性あり。

- **オフ推奨**: 月額超えたら完全停止したい場合
- **$1〜$20設定**: 少しだけはみ出てもOKな場合

## 2. anthropics/skills リポジトリとは

Anthropic公式が公開しているスキル集。GitHubから無料でダウンロードできる。

### ダウンロード方法

```
1. GitHubの https://github.com/anthropics/skills を開く
2. 緑色の「Code」ボタン → URLをコピー
3. Claude Codeのチャット欄に貼り付けて「このファイルをダウンロードしてください」
4. → git cloneが実行される
```

### 公式スキルの中身（例）

| スキル名 | できること |
|---------|-----------|
| algorithmic-art | JSを使ったジェネラティブアート |
| canvas-design | PDF/PNG形式のポスター・ビジュアルデザイン |
| frontend-design | 高品質なWebコンポーネント・LP・ダッシュボード |
| team-factory | スライド・ドキュメント（HTML） |
| **skill-creator** | **スキルを作るスキル（今日の主役）** |

## 3. スキルとは何か

```
スキル = 人間がやっている仕事の一部をAIでもできるように移管したもの
       = 一連の手順書
       = 繰り返しの作業をワークフローでまとめたもの
       = ワンコマンドで起動する自動化フロー
```

### 具体例

| 人間がやっていた作業 | スキル化すると |
|---------------------|--------------|
| 電子書籍の現稿を作る | `/ebook-gen` で起動する自動化フロー |
| 表紙をデザインする | `/cover-design` コマンド一発 |
| Xに投稿する | `/post-x` で自動投稿 |

---

## 4. グローバルスキルとプロジェクトスキルの違い

| 種類 | 場所 | 動くフォルダ |
|------|------|------------|
| グローバルスキル | `~/.claude/skills/` | **どのフォルダでも動く** |
| プロジェクトスキル | ダウンロードしたフォルダ内 | そのフォルダのみ |

### ポイント
- anthropics/skillsをクローンして使う = **そのフォルダのみ**で動く
- デジーナエージェントから入ってきたスキル = グローバルに入っているので**どこでも動く**
- スキルをグローバルに移したい → `.claude/skills/`に置けばOK

---

## 5. スキルクリエイターの使い方

### インストール手順

```
1. anthropics/skillsをgit cloneでダウンロード
2. skills/skill-creator/ フォルダを .claude/skills/ にコピー
3. Claude Codeを再起動（/exit → claude）
4. /skill と打つとスキルクリエイターが候補に出てくる
```

### スキルの起動方法

| 種類 | コマンド |
|------|----------|
| スキルを起動 | `/スキル名` |
| 候補から選ぶ | Tab キーで補完 |
| インストール済み一覧 | `/skills` |

---

## 6. スキルクリエイター実演：チャットサマリースキル

### 作ったスキル

「チャットの履歴を終了時にまとめてMarkdown + 画像で保存するスキル」

### スキル作成の流れ

```
① スキルクリエイターを起動（/skill-creator）
② どんなスキルを作りたいか答える（対話形式）
③ 出力形式・保存先・スタイルを指定
④ 自動でスキルのMDファイルが生成される
⑤ テスト実行 → 修正 → 本番実行
```

### 作成時のコツ

- 最初はシンプルなスキルから始める（工程数が少ないもの）
- ✅ 簡単：表紙を作る・文体を変える・まとめを作る
- ❌ 難しい：電子書籍をまるまる作る・漫画フルページを作る
