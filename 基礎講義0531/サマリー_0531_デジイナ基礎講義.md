## バイパスモード（パーミッションスキップ）

```
claude --dangerously-skip-permissions
```

- 許可確認ダイアログを全スキップ。快適にサクサク動く
- Claude Codeアプリでは「**バイパスモード**」が相当
- 先生はこのモードで4ヶ月間ほぼ使用してきた

### 5つの実行モード（Shift+Tabで切替）

| モード | 説明 |
|--------|------|
| 許可確認モード | 毎回ダイアログで確認 |
| 編集承認モード（Accept Edits） | 編集のみ確認 |
| プランモード | 実行前に計画だけ提示 |
| 自動モード（Auto / Access Edits On） | ほぼ自動、少し緩い |
| バイパスモード | 全スキップ、最速 |

## @・/コマンドでエージェント・スキルを呼び出す

- ターミナルで `@` → このフォルダーで使えるエージェント候補一覧が出る
- ターミナルで `/` → スキルコマンド候補一覧が出る
- 候補が出たら**Tabキー**で確定（Enterだと送信してしまう）
- 候補が表示されない場合 → **「このフォルダーでスキルを使えるようにセットアップして」とClaudeに依頼**

## パスの概念（グローバル vs 作業ディレクトリ）

| 種別 | 場所 | 有効範囲 |
|------|------|---------|
| グローバル | `~/.claude/` | どの作業フォルダーでも使える |
| 作業ディレクトリ | 選択したフォルダー内 | そのフォルダーのみ |

- `~/.claude/` に `agents/` と `skills/` を置くと、どこでも呼び出せる
- デジイナエージェントを特定フォルダーで使う場合はそのフォルダーを作業ディレクトリに指定

## CLAUDE.md の役割

- Claude Code 起動時に**最初に自動で読み込まれるルールファイル**
- 場所：`~/.claude/CLAUDE.md`（グローバル）または作業フォルダー内（プロジェクト別）
- ここに「ファイルを削除する前に必ずコピーを保存して」などのルールを書いておける

## ターミナル ≠ チャット欄（重要）

- **ターミナルで行った会話は、左のチャット欄には引き継がれない**
- ターミナルで要件定義を作っても、チャット欄はその内容を知らない
- ターミナル内の作業に関する質問は、**ターミナルの中で続けてすること**
- スクショを撮ってチャット欄に貼る方法でもOK（特に英語エラー文の翻訳など）

### BTWコマンド

```
btw: ここわからんのだけど教えて
```

- セッションの流れ（コンテキスト）を途切らせずに、**別口で**質問できるコマンド
- ターミナルで作業を続けながら疑問点だけ挟める

## 壁打ちのコツ（コンテキスト汚染に注意）

- 壁打ちが長くなるとAIは最初に言ったゴールを忘れがち
- **対策**：定期的に「私はこれが作りたい」とゴールを再度明示してから改善計画を出してもらう
- 人間も同様。講義視聴しながら操作すると両方が曖昧になる（コンテキスト汚染）
