## 4月24日 ゲリラ講義サマリー：Obsidian × Claude Code 記憶管理システム

### テーマ・概要
Claude Codeの会話履歴・作業メモをObsidian（オブシディアン）に蓄積させ、AIが過去の作業を覚えている状態を作る「ハイブリッドメモリ」構築の実演。約2時間30分の配信。

---

### 主な内容

#### Obsidianとは
- メモを蓄積するローカルアプリ
- Source DrawnでインジェストするとWiki（知識ベース）が生成され「Vault（ボルト）が育つ」仕組み
- Claude Codeと組み合わせた「クローディアン」というプラグインも登場

#### 実演した内容
- Obsidian × Claude Code の連携セットアップ
- 今まで散らばっていた作業メモ・URLをObsidianに集約
- 将来的には検索履歴を自動収集して毎日レポートを作る仕組みを目標に
- パイプライン設計書の読み込み・レポート作成なども実演

#### デジイナエージェントの内容紹介
- **ナノバナナジ**スキル：サムネイル・スライド用図解が高品質に出る
- **Eブックデジ**スキル：電子書籍の図・漫画を一気に生成するスキル
- スキルファインド：既存の公開スキルを探してくれるスキル

#### 学習サイトの整備状況
- アーカイブ・拡張機能集・GitHubスキル集などを学習サイトに追加中
- お気に入り機能・読み込み中アニメーションなども実装済み

---

### 学んだこと・ポイント
- Claude Codeは会話履歴が蓄積されているようでされていないため、Obsidianで外部記憶を作ることが重要
- 「わからないことはClaudeに任せてYesを押せばだいたい終わる」が鉄則
- 言語化できないものはAIに「言語化を手伝ってもらう」ことで壁を突破できる
