**DEJIINA AGENT — スタートガイド**

# **はじめにお読みください**

このガイドの通りに進めれば、3ステップで Dejiina Agent を使い始められます。  
むずかしい設定やコマンドはありません。

## **Dejiina Agent とは**

デジタルコンテンツ制作・マーケティング・出版に特化した、Claude Code 用のAIエージェントです。テーマを伝えるだけで、リサーチから成果物の作成までを自動で進めます。

| できること | 例 |
| :---- | :---- |
| リサーチ | 競合調査・市場分析・出典付きレポート |
| 電子書籍・Kindle出版 | 構成・原稿25,000字・挿絵・漫画化・DOCX出力 |
| YouTube・動画制作 | 企画・台本・ショート動画・サムネイル |
| SNS・マーケティング | X / note / LP / VSL / ステップメール |
| システム設計 | 要件定義・SDD・API設計 |

## **使い始める前に（準備するもの）**

**Claude Code** がパソコンにインストールされていること。

まだの場合は https://claude.ai/code からインストールしてください。インストール後、ターミナルで claude と打って起動できれば準備完了です。

## **導入は3ステップ**

* **受け取った ZIP ファイルを解凍する**  
  お渡しした ZIP ファイルを展開してください。  
  1. ・ **Mac**：ZIP をダブルクリック  
  2. ・ **Windows**：ZIP を右クリック →「すべて展開」  
* 解凍すると、.claude や scripts などが入ったフォルダができます。**これが本体フォルダ**です。デスクトップなど分かりやすい場所に置いてください（置き場所・フォルダ名は自由です）。  
* **本体フォルダを Claude Code で開く**  
  解凍してできた本体フォルダを、そのまま Claude Code で開きます。  
  **かんたんな開き方**  
  1. Cursor または Claude Code デスクトップアプリを起動し、ダウンロードした「デジイナエージェント」のフォルダを選択する  
  2. ターミナルを開き、claude とだけ入力して Enter を押す

**作業フォルダを作って、指示する**  
Claude Code が起動したら、入力欄に「作業フォルダを作って〜」と指示します。成果物はその作業フォルダの中に保存されます。  
▼ 入力例  
「myproject」というフォルダを作って、その中に

* 『AIを使った副業の始め方』の電子書籍を生成して  
  → 本体フォルダの中に myproject フォルダが作られ、原稿・画像などの成果物がそこに貯まっていきます。  
  案件ごとにフォルダを分けたいときは、フォルダ名を変えて指示するだけ（例：案件A、案件B…）。

## **使い方の例**

入力欄で、エージェント（@名前）またはスキル（/名前）を呼び出します。@ や / を打つと一覧が出ます。

## **困ったとき（よくある質問）**

* **Q. / を打っても dejiina のスキルが出てこない**  
  A. **本体フォルダ（.claude が入っているフォルダ）そのもの**を Claude Code で開けているか確認してください。別の場所や、本体の外側のフォルダで開くとスキルは出てきません。STEP 2 をやり直してください。  
* **Q. 本体フォルダを別の場所に移動してもいい？**  
  A. はい、自由に移動・名前変更してかまいません。移動後は、移動先のフォルダを STEP 2 の手順で開き直すだけです。  
* **Q. 作った成果物はどこに保存される？**  
  A. STEP 3 で指定した作業フォルダ（例：myproject）の中です。本体フォルダの中にできます。  
* **Q. 新しいバージョンを受け取ったら？**  
  A. 新しい ZIP を解凍し、**古い本体フォルダの中にある作業フォルダ（案件◯◯など）を、新しい本体フォルダへ移動**してください。そのあと古い本体フォルダは削除してかまいません。大切な作業フォルダは別の場所にもバックアップしておくと安心です。

## **注意事項**

**● 本体フォルダの中身を壊さないでください**  
.claude フォルダと scripts フォルダは削除・名前変更しないでください。Dejiina Agent が動かなくなります。
