## 1. エージェントとは何か

**Claude Codeそのものがエージェント**。

```
人間 → 指示 → [エージェント（Claude Code）] → 作業 → アウトプット
```

エージェントの仕事:
- 指示を受け取る
- 状況を判断する
- 必要なツール・スキル・資料を使う
- 最後まで作業を進めてアウトプットを出す

---

## 2. CLAUDE.mdの役割

起動時に**最初に読み込まれる**ルールファイル。

| 場所 | パス |
|------|------|
| グローバル（全プロジェクト共通） | `C:\Users\ユーザー名\.claude\CLAUDE.md` |
| プロジェクト別 | `プロジェクトフォルダ\.claude\CLAUDE.md` |

### 注意点
- 強制力はお願い程度（10回中1回ぐらいルールを無視することがある）
- 強固なセキュリティにしたい場合は **Hooks** を使う
- ただしHooksを入れると毎回許可を求められて鬱陶しくなる

### セキュリティ vs 快適さのトレードオフ

| 強度 | メリット | デメリット |
|------|----------|------------|
| CLAUDE.mdのみ | 快適・ストレスなし | ルールが無視されることがある |
| Hooks導入 | ルール厳守 | 毎回許可確認が必要・遅くなる |

**個人作業ならCLAUDE.mdのみで十分。** 他人の秘密情報を扱うならHooks検討。

## 3. コンテキストの概念

### コンテキストとは

```
AIが今見ている作業記憶 + AIに与えた情報 = コンテキスト
```

例え話：講義を聞きながら料理しながら彼女の悩みも抱えている状態 → 情報が多すぎて何も頭に入らない。AIも同じ。

### コンテキストが溢れると起こること
- 大事な指示を見落とす
- 判断がブレる
- 前のことを忘れる

### 対処コマンド

| コマンド | 動作 | 使うタイミング |
|----------|------|----------------|
| `/compact` | 会話履歴を要約・整理（自動でも起動する） | コンテキストが増えてきたとき |
| `/clear` | コンテキストを完全クリア・新セッション開始 | あまり使わない（消えてしまうため） |

## 4. サブエージェントの概念

### サブエージェントとは

メインエージェント（Claude Code）が呼ぶ**専門家の部下**。

```
Claude Code（エージェント）
    ├── @現稿専門エージェント（サブエージェントA）
    ├── @表紙専門エージェント（サブエージェントB）
    └── @まとめ専門エージェント（サブエージェントC）
```

### 最大のポイント：独立したコンテキストウィンドウ

```
メインセッション（汚れない）
    ↓ 指示を出す
サブエージェント（別の部屋で作業）
    ↓ 結果だけ返ってくる
メインセッション（結果だけ受け取る）
```

例え話：講義に集中したいから料理は奥さんに頼む。「できたよ」という結果だけ受け取る。

### メリット・デメリット

| メリット | デメリット |
|----------|------------|
| メインのコンテキストが汚染されない | トークン消費が少し増える場合がある |
| 専門タスクに集中できる | |
| 精度が上がる | |

## 5. スキルとサブエージェントの関係

```
スキル = 仕組み・手順書
サブエージェント = スキルを持って動く専門家
```

| 項目 | 説明 |
|------|------|
| スキル | 「電子書籍を作る手順書」 |
| サブエージェント | 「電子書籍作る手順書を持っている専門家エージェント」 |

→ **スキルを作り続けてきたのはこのため！** サブエージェントに持たせるため。

---

## 6. サブエージェントの呼び方

| 種類 | コマンド |
|------|----------|
| スキルを呼ぶ | `/スキル名` |
| エージェントを呼ぶ | `@エージェント名`（Tabキーで確定） |
| インストール済みエージェント確認 | `/agents` |

## 7. スキルクリエイターの内部構造（参考）

`agents/`フォルダの中には3体のサブエージェントが定義されている：

| エージェント名 | 役割 |
|----------------|------|
| grader（採点担当） | スキルの出力を採点 |
| 比較担当 | 改善前後を比較してどちらが良いか判定 |
| 分析担当 | なぜそうなったかの原因分析 |

サブエージェントのファイル構成（必須要素）:
```markdown
- name: エージェント名
- description: 概要
- 役割
- 使用スキル
```

## 9. お役立ちコマンド

### /btw コマンド（今日の新コマンド）

メインセッションのコンテキストを**汚さずに**一時的な質問ができる。

```
使い方: /btw [Tab] → 質問入力
戻り方: ESCキー
```

例：長い作業セッション中に「ちょっとこのエラーコードだけ聞きたい」という時に使う。

### claude --agents（今日のお土産）

```bash
claude --agents
```

→ ターミナルで起動すると**分割ビュー**になる。複数のエージェントを同時に監視・管理できる。
