# Codex 起動手順

## 毎回の起動方法（2ステップ）

### ステップ1：PowerShellを開く
- スタートメニューで「PowerShell」と検索して開く
- （管理者でなくてOK）

### ステップ2：以下を1行ずつコピペしてEnter

```
cd "C:\Users\kazuk\OneDrive\デスクトップ\ツール開発A"
```

Enterを押したら次に：

```
codex
```

Enterを押すと起動完了。

---

## 使い方

- 起動したら入力欄に**日本語で話しかけるだけ**でOK
- 手入力しなくても大丈夫（ファイル操作・コード変更などは自動でやってくれる）
- パスワード・認証コードなど本人確認が必要なものだけ手入力が必要

---

## 終了方法

```
/exit
```

または `Ctrl + C` を押す
