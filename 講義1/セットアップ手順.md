# 講義1 - TAISUN Agent セットアップ手順

## 実行したコマンド

```powershell
# 1. PowerShell の実行ポリシー設定（初回のみ）
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

# 2. ホームディレクトリに移動してリポジトリをクローン
cd $HOME
git clone https://github.com/taiyousan15/taisun_agent.git

# 3. フォルダに移動してインストールスクリプトを実行
cd taisun_agent
.\scripts\install.ps1
```

## インストール結果

- バージョン：v2.53.3
- スキル：59個
- エージェント：95個
- MCPツール：25個登録

## 次にやること

1. `.env` ファイルを開いて `ANTHROPIC_API_KEY` を設定
   - ファイルの場所: `C:\Users\kazuk\taisun_agent\.env`
   - `ANTHROPIC_API_KEY=sk-ant-...` を追記

2. `taisun_agent` フォルダで Claude Code を起動
   ```
   claude
   ```

3. 「使い方を教えて」と話しかける

## 備考

- `uv` 未インストール（Python系の一部機能が使えない）
  - 後でインストール: `winget install astral-sh.uv`
- `Ollama` 未インストール（一部スキルで必要）
  - 対象: sdd-full / sdd-design / sdd-req100 など

## アップデート方法

```powershell
.\scripts\install.ps1 -Update
```
