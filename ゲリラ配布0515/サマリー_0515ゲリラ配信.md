# 5月15日 ゲリラ配信サマリー：コミクルネオのコデックス移管・サブエージェント深堀り

---

## テーマ・概要

コミクルネオ（電子書籍・漫画自動生成システム）をClaude CodeからCodexへ移管する作業を生配信で実施。移管がうまくいかなかった原因を2時間半かけて特定・解決した。

---

## 主な内容

### サブエージェントとスキルの基礎

| 概念 | 内容 |
|------|------|
| メインエージェント | Claude Code（皆さんが使っているチャット欄） |
| サブエージェント | メインの下で動く。スキルがないと動かない |
| 別コンテキスト | サブエージェントは別の「思考空間」で動くため、メインのコンテキストが汚染されない |

- コンテキスト汚染の例え：Zoomの講義を聞きながらスマホ・テレビ・漫画を同時進行 → 何も頭に入らなくなる → Claudeも同じ
- サブエージェントを使うとリサーチを3体並列で走らせられる（公式情報担当・トレンド事例担当など）

### Claude Codeデスクトップアプリの進化（新発見）

- **ターミナルがアプリ内で動く**ようになった
- フォルダ選択もデスクトップアプリ内で完結
- Codexも同様にフォルダ指定でClaude起動可能
- → **Cursorが不要になるかも**という結論

### コミクルネオのコデックス移管：問題発生から解決まで

**背景**: GPTイメージ2が登場し、コデックス（ChatGPT Plus）のサブスク範囲内で画像生成したい

**電子書籍・漫画自動生成パイプライン**:
```
テーマ決め
  → Ebookリサーチ（サブエージェント並列）
  → 現稿作成（マニュスクリプト）
  → 差し絵プロンプト生成（現稿完成後に作成）
  → 中間成果物
  → 漫画シナリオCSV
  → 漫画ページ画像生成
```

**差し絵プロンプトが現稿の後に作られる理由**: 文脈・読者の理解順・説明との繋がりを見た上で差し絵を整えられるから

**発生した問題**:
- 漫画シナリオCSVが正しく作られない（同じページが永遠に繰り返される）
- Codexがスキルの指示を全無視する

**原因（2時間半後に判明）**:
- Claude Code用の `.claude` フォルダ内のスキルドキュメント（SK.MD）が、Codex用の `.agents` フォルダに正しく移管されていなかった
- 移管されたファイルの中身がスカスカ（50行 vs 1200行）だった

**解決策**:
- `.claude` フォルダの中身を `.agents` フォルダにそのままコピー
- これによりCodexもスキルの詳細な手順を読めるようになる

### Claude Code vs Codex フォルダ構成

| 項目 | Claude Code | Codex |
|------|-------------|-------|
| 設定・スキルの置き場 | `.claude/` フォルダ | `.agents/` フォルダ |
| サブエージェント | エージェント用フォルダ | `.agents/` 内に含む |

### コミクルGPT v3.0（初出し・動作確認中）

- ChatGPT上で動くコミクル（GPTとして構築）
- 今回の生配信で初公開・動作確認
- OpenAI APIエラーが発生 → 原因調査中

## 学んだこと・ポイント

- **スキルファイル（SK.MD）の中身をちゃんと読む** ← 今回の一番の教訓
- スキルを別ツール（Codex等）に移管するときは、`.claude`フォルダの中身が正しくコピーされているか中身を確認する
- ファイルが空・スカスカになっているとAIは何もできない（アンポンタンなのはAIではなくファイルが原因）
- サブエージェントはリサーチの速度を上げる強力な手段（複数体が別コンテキストで並列動作）
- スキルを作る場所と使う場所は統一するのが原則（Claude Codeで使うならClaude Codeで作る）
