## フェーズ1：お知らせ・環境整備（0:00〜18:30）

### Claude Code 使用制限の注意
- **5時間ごとのセッション制限**と**週間制限**がある
- 追加使用料はデフォルトでオン・20ドル上限 → **必ずオフまたは上限1ドルに設定**
- 自動チャージもオフ推奨（意図せず課金され続けるリスク）
- サブ並列実行30体で一瞬で容量突破した事例あり（追加料金発生）

### 学習サイトのログイン問題
- 決済時のメールアドレスとアカウントの紐付けを実装中
- 決済メール以外でログイン → アクセスパスワードが必要
- アクセスパスワードは定期変更予定（会員限定公開）
- 解除方法：決済メールをアカウントに紐付けるか、正しいアドレスで再登録

### Max プランのボーナス
- 数ヶ月使用後に紹介リンクが発生（100ドルクレジットの可能性）

## フェーズ2：Cursor / Claude Code の基本操作（18:30〜50:00）

### 起動フロー
1. Cursor を起動 → プロジェクト（フォルダー）を選択
2. `Cmd+J` でターミナルを起動
3. `claude` または `claude --dangerously-skip-permissions` で Claude Code を起動

### ディレクトリの概念
- Cursor左側 = 選択中フォルダーの中身（Windows: エクスプローラー / Mac: Finder）
- **親フォルダー**（作業ルート）と**子フォルダー**（サブディレクトリ）の関係
- 親フォルダーで開いていれば子フォルダーのスキルも使用可能
- フォルダーを増やしすぎると横タブが多くなり混乱するため、プロジェクトごとに選択推奨

### グローバルフォルダー（~/.claude/）
- Windows: `C:\Users\ユーザー名\.claude\`
- **ここに入っているスキル・CLAUDE.mdはどのフォルダーでも動く**
- ただしここに読み込ませる量が多いほど起動時にコンテキストを消費する

### スキルの配置場所の判断
| 配置先 | 適する用途 |
|--------|-----------|
| グローバル（~/.claude/） | リサーチなど、どのプロジェクトでも使うもの |
| プロジェクトローカル | 漫画作成・経費計算など、特定プロジェクト専用のもの |

### Collaborator（Macのみ）
- カーソルより柔軟にターミナルの配置・リサイズが可能
- **メモリ32GB以上のMacユーザーに推奨**
- ただし非常に重い

## フェーズ3：スキルとは何か（50:00〜1:47:00）

### AIの基本原則
- **入力 → 出力** が全ての基本
- 曖昧な入力には曖昧な出力しか返ってこない → 具体的な指示が重要

### プロンプトとは
> 「期待する結果を得るための指示」

- プロンプトエンジニアリングの時代はすでに終わり
- プロンプト単品の販売・習得は価値が下がっている

### スキルの定義
> 「特定のタスクをこなすための手順や指示を一まとめにした、再利用可能なプロンプトのパッケージ」

**コンビニのレジの比喩**
| 要素 | 対応 |
|------|------|
| お客さんが渡す商品 | インプット（指示・テキスト） |
| コンビニ店員 | エージェント |
| バーコードリーダー（レジ） | **スキル** |

→ レジ（スキル）があることで、どんな商品（入力）でも正確に計算（処理）できる

### スキルの作り方
1. **自分がやりたいこと・やっている作業を整理する**
2. その作業フローを Claude Code に伝える
3. 「今やった流れをスキル化して」と指示する → SKILL.md が生成される

**例：コミクルCSV作成スキル**
```
原稿作成 → 漫画シナリオ化 → コマ割り → CSV出力
```
この4ステップをまとめたものが1つのスキル。

### スキルの限界と注意
- **自分が知っていることしかスキル化できない**
- 知らないことはシステム・ツールで補う（Claude Code の得意領域）
- スキルを作る過程でスキルが自然と身につく

### 成長の差が出始めている
- サポート受講者はスキル・ツールをバンバン作り始めている
- 理解よりも「触る時間」が成長の鍵
- 分からないことは Claude Code に聞く → 繰り返すことでブロックが取れる

### 宿題
- **やりたいことをリストに書き出してスキル化する**
- 配布スキル（コミクルネオ・電子書籍漫画自動化）の中身を見て構成を参考にする

## 重要ポイント（次回持ち越し）

- スキルはいくつでも作れるが、グローバル登録は厳選する（コンテキスト節約）
- プロンプトの長文化 → スキル化の流れが基本
- 知識よりも実践：分からない状態でも触りまくることが最速ルート
