## 概要

コミュニティ運営を自動化する「コミュニティパイプライン」の設計と要件定義をライブで行った配信。Discord AI秘書の構築・YouTube自動アップ・SNS自動投稿の全体フローを整理し、GitHubリポジトリ「community-pipeline-モカちゃん」として管理開始。

---

## フェーズ1：やりたいことの整理・全体ワークフロー

### 核心ゴール
```
MP4ファイルをDiscordに渡す
  ↓
YouTubeに自動アップ（非公開）
  ↓
学習サイトへ反映（動画リンク）
  ↓
文字起こし → X / Threads / Note 自動投稿
```

### Discord内 AI秘書（エージェント）の役割
- ユーザーがDiscordにMP4を送る受付窓口
- 定期配信 / ゲリラ配信の自動振り分け
- 下書き生成 → **グッドリアクションで承認** → SNS投稿実行
- コミュニティへの全体通知

### 既存リソースの活用
- **パーフェクトボット**（旧ポイント管理システム）→ ボット基盤として流用

## フェーズ2：AI秘書のリサーチ結果

### SNSトレンド調査（Claude CodeでWebリサーチ実施）
- イケハヤさんが「AI秘書テンプレ配布」でトレンドトップ
- Claude Code 2.0（2025年9月29日リリース）が起爆剤
- Opus 4.7（4月16日リリース）なども時系列で整理

### 実装コスト試算
| 方式 | コスト |
|------|--------|
| Whisper API（文字起こし） | 月400〜640円 |
| ローカル（Mac Studio M4 Max） | 設定コストあり・運用無料 |
| **→ 結論：APIが圧倒的シンプル** | |

### 常時稼働の選択肢
- **VPSサーバー（Xserver等）**：24時間稼働、OpenClaw等を外部環境で動かせる
- **Mac Mini**：手元にあれば活用可能
- **Cloudflare Workers**：無料枠あり（軽量処理向け）

## フェーズ3：要件定義書の作成（バージョン1.1完成）

### Discordサーバー設計
- **サーバー名**：デジイナAI大学
- **会員区分**：有料会員 / 無料会員（2区分のみ）
- **ロール付与**：決済情報とDiscordユーザーIDを紐付け
- **退会時**：ロール剥奪 → チャンネル閲覧不可に自動移行

### AI秘書の動作原理（Claude Code との連携）
```
[DiscordボットがトリガーをキャッチPython]
     ↓
[Claude CLI が CLAUDE.md を読み込む]
     ↓
[CLAUDE.md の指示に従いAIが処理実行]
```
- プログラムが動く部分：Discordボット（トリガー検知・投稿）
- AIが介入する部分：CLAUDE.mdを読んだClaudeが判断・文章生成
- **ポイント**：AIが介入する箇所を明確に切り分けることがシステム設計の核心

### YouTube自動アップロード
- **YouTube Data API v3**で非公開アップロード
- タイトルのみ渡してアップ（詳細概要欄は空）
- 子供向けでない・限定公開で設定

### SNS自動投稿
- **Publer**等のSNS統合管理ツール（月10ドル前後）を検討
- X・Threads・Noteに対応

## フェーズ4：スキルとシステム・ツールの違い（重要な気づき）

### 使い分けの原則
| | スキル | システム・ツール |
|--|--------|----------------|
| 作れる条件 | 自分が知っていること | 知らなくてもClaudeが実装 |
| 作り方 | 作業フローを渡す | 要件定義 → Claude Codeが実装 |
| 難易度 | 比較的低 | AIの介入が増えるほど高 |

### 重要メッセージ
> 「コミュニティパイプラインはスキルではなくシステムを作っている。  
> そのシステムを作る過程のワークフロー・ログが最終的にスキルになる。」

→ 北極星（ゴール）を持って進んでいくと、気づいたらスキルが身についている

## フェーズ5：マネタイズ戦略のシフト

### 現状認識
- **YouTubeの広告収入は不可能**（AI規制が入った）
- 電子書籍の印税収入も単体では限界

### これからの戦略
```
YouTube / 電子書籍
  ↓（アクセス・興味を集める）
公式LINEなどへリスト集客
  ↓
自社商品のオファー
  ↓
収益化
```
- **リスト集客が最重要**
- プラットフォームに依存しない収益構造を作る
